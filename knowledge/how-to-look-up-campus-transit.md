# How to look up campus transit (do not memorize fares)

Campus-Pass must open **current official pages**. This file is a search recipe, not a fare table.

## Search order

1. `[university] parking and transportation` or `[university] transportation services`
2. `[university] U-Pass` / `UPASS` / `student bus pass`
3. `[city] transit student fare`
4. Campus shuttle / night safe-ride / escort
5. Agency service alerts for that day

## What to capture

| Field | Where it usually lives |
| --- | --- |
| Eligibility | Transportation FAQ, bursar / student fees page |
| Covered agencies | U-Pass partner list |
| How to board | "Tap campus ID", mobile app, sticker on ID |
| Shuttles | PDF or live map on the transportation site |
| Safe-ride | Public safety site, not the transit blog |

## Hard rules

- If the official page disagrees with a blog or Reddit thread, use the official page.
- If the campus has multiple, name them (main campus vs medical campus vs downtown).
- Airports, Amtrak, and intercity buses are usually **not** on a campus U-Pass. Check before promising a free ride.
